# Real-World Data Project — Retail Sales Analysis

## Project overview
This project analyzes a realistic synthetic retail-sales dataset for applied data science practice.

**Domain:** Retail  
**Dataset:** 1,200 transactions covering January–December 2025  
**Currency:** Indian Rupees (INR)

## Objectives
1. Understand overall sales and profitability.
2. Compare sales across product categories and regions.
3. Identify top-performing products.
4. Examine payment-method usage.
5. Visualize monthly sales trends.
6. Communicate actionable business conclusions.

## Files
- `data/retail_sales_data.csv` — main dataset.
- `analysis.py` — complete Python analysis script.
- `Retail_Sales_Analysis.ipynb` — notebook version of the analysis.
- `Retail_Sales_Project_Report.pdf` — ready-to-submit report.
- `Retail_Sales_Project_Report.md` — editable report source.
- `charts/` — generated visualizations.
- `output/` — KPI and summary CSV files.
- `requirements.txt` — Python packages.
- `README.md` — project instructions.

## How to run
```bash
pip install -r requirements.txt
python analysis.py
```

For the notebook:
```bash
jupyter notebook Retail_Sales_Analysis.ipynb
```

## Dataset note
The dataset is **synthetically generated for educational purposes**. It does not contain real customer identities or confidential information.
